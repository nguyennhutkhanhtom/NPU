# Functional repair contract

This repair supersedes the parameterization-only restriction. The original review and `scale/baseline` remain historical evidence. Five pipeline stages, 13-bit ISA, 8 vector registers, 32 lanes, 512 elements/vector, 512x512 ternary matrices and a nine-level combinational reduction tree remain.

- Signed Q4.F: W=16/F=12 and W=8/F=4. ADD/SUB/MUL/DIV and final TMATMUL quantization saturate to signed MIN/MAX. MUL uses arithmetic right shift (floor); DIV truncates toward zero. Division by zero sets overflow and returns signed extremum; 0/0 returns zero with overflow. ADD carry and SUB borrow are unsigned flags, independently of signed saturation.
- EXP/SIG tables cover every signed raw input, ordered MIN to MAX, generated using nearest rounding and signed saturation. EXP underflow rounds to zero. These generated numeric tables replace missing tables, not trained model weights.
- NORM is RMS of the full 512-element vector, no gamma: epsilon is one raw-input squared unit. Integer mean-square is rounded down; the square root retains F fractional guard bits; final division truncates toward zero and saturates. Zero normalizes to zero.
- Internal read/write requests are one-cycle start pulses accepted when idle. Descriptors are latched. Read valid/ready and write valid/ready control each beat; done pulses occur only after the last accepted beat. Reset aborts in-flight work and clears control/valid, not RAM contents.
- Vector RAM: 8 banks x 8 vectors x 16 words at 0..1023. Normal LDV/STV use bank=instruction[5:3], source/destination vector=instruction[2:0]/[8:6]. Matrix storage starts at word 1024, with 8 matrices of MATRIX_WORDS words. TMATMUL uses matrix selector [2:0], activation vector [5:3] in vector bank 0, destination [8:6] in bank 0. Lane 0 occupies the least significant DATA_WIDTH bits; ternary row-major weights use 00=0, 01=+1, 11=-1; 10 is reserved.
- Separating matrix storage prevents vector writes corrupting weights. Scaled RAM depth becomes 32768 (15 address bits), enough for 1024+8*2048 words; default remains 524288. Existing external memory images need this documented mapping.
- A conservative transaction interlock holds the next instruction until all writes of the current vector complete. Beats still flow through the five pipeline stages. This changes instruction overlap/latency and requires fresh synthesis/timing characterization.
- Arithmetic uses destination [8:6], source a [2:0], source b [5:3]; unary EXP/SIG/NORM use source a. HALT is opcode 1111 regardless of operand bits, and ready is sticky after earlier transactions drain. Falling past the configured ROM depth supplies a HALT without PC wrap. Opcode 0000 is NOP. Reserved or unknown instructions have no write side effects; simulation reports invalid instructions. Synthesized invalid-opcode handling halts with ready=1, overflow=1 and the offending instruction in debug outputs.
- DDR adapter is standalone, one complete UI data word per memory command (4:1 MIG/BL8 style). Request addresses count UI words; app addresses have a separate width. WDF END marks every command's single data word, not only the final word of the host request. Source data is provided one clock after wr_burst_data_req and buffered through backpressure. A zero length completes as a no-op; unrepresentable address ranges complete with an error indication. UI reset or calibration loss aborts the transaction.

The numeric policies and memory-map clarification are implementation decisions where the PDF was incomplete. Original trained weights/tokenizer/executable workload cannot be reconstructed from missing inputs; generated validation programs are not a claim of LLM accuracy.
