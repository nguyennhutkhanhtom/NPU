The legacy MNIST runners/exporter/testbench have been retired. This directory
retains the original [results](results.json), [checkpoint provenance](checkpoint_history.json),
[upstream manifest](upstream_manifest.json), reference metadata and compact
memory/program fixtures for inspection. These results describe the legacy core
and do not satisfy the full `llm_soc` language application gates.

Deleted execution scripts remain recoverable at Git commit
`d9ed7921d42731a198f565785a8ae79b20c7c79e`. No new legacy application is launched
from the current repository.
