Description and Recommendations [hide details]

Multiplexer restructuring during synthesis can produce logic that is slower, affecting the performance of this design.

The following suggestions may help resolve this issue:

  • In the Assignment Editor, turn off Restructure Multiplexers for the hierarchies that contain the nodes on the affected paths.
