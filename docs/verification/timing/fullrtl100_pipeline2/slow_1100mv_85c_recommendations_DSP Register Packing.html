Description and Recommendations [hide details]

The listed paths include data path delays that go through DSP blocks that are not fully utilizing internal DSP register banks. Performance of this path may be improved by taking advantage of additional register stages embedded inside the DSP block hardware. Full use of embedded DSP register stages is recommended to achieve maximum design performance.

The following suggestions may help resolve this issue:

  • Optimize the HDL to include free registers around DSPs to be packed into internal DSP register banks of the DSPs in the design. Instantiate DSP blocks using Altera Megafunctions templates to ensure full utilization of internal DSP register banks.
  • DSP blocks may need multiple free registers at the input end, and one register at the output end to be able to fully utilize its internal DSP register banks. Refer to Altera Documentations on Altera's website for more information on Altera DSP architectures for your device family.
  • Refer to DSP Block Details table in Fitter Report for more information on internal DSP register banks utilization of the specific DSP block.

See the Top Recommendations section for potential solutions for each path.
