Description and Recommendations

The listed paths contain global routing resources that may be detrimental to timing when they appear on the datapath. Global routing is typically used for low-skew control signals with high fanout and can appear on a datapath if a signal is promoted through an instance assignment or automatically promoted by the Fitter.

The following suggestions may help resolve this issue:

  • Remove any instance assignments that force promotion of the offending signal to a global resource.
  • Add a GLOBAL_SIGNAL OFF assignment to forbid promotion of the signal for the affected portions of the paths.

See the Top Recommendations section for potential solutions for each path.
