Overview

The Description and Recommendations section gives general advice and recommendations for addressing Inter-path Competition.

The Aggregate Results section shows the Node Name and the number of occurences of the Node Name in the identified paths. You can sort the table by clicking the column header.

The Top Recommendations section lists recommendations for the most serious issues identified by the analysis. The number of stars indicates the relative importance of each recommendation, with five stars identifying the most important recommendations. Click show details for more information about each recommendation; click report timing to generate a timing report for the listed path.

The Detailed Results section contains the detailed report for this analysis. Click on show details for more information related to the recommendation for each path; click on report timing to generate a timing report for the listed path. You can sort the table by clicking the column header.

Description and Recommendations

Nodes on each listed path have fanouts in other timing paths. These paths have conflicting optimization goals. This conflict results in the placer finding a globally optimal solution which is not optimal for each individual path.

The following suggestions may help resolve this issue:

  • Replicate the recommended nodes or related logic in the appropriate HDL code.
  • Enable Physical Synthesis duplication.
  • Use the Manual Logic Duplication or Maximum Fan-Out logic options to create duplicate nodes.See documentation for details on these logic options.

See the Top Recommendations section for potential solutions for each path.
