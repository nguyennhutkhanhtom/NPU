# llm_gumbel_lut.svh

> **Role:** Combinational S24/F16 samples of -ln(-ln((index+0.5)/256)).
> **Scope:** CURRENT. **Category:** GUIDE.
> **Source:** [llm_gumbel_lut.svh](<../../../Verilog Source code/llm_gumbel_lut.svh>).

## Important contracts

`llm_gumbel_sample` takes an 8-bit index covering 0…255. The parent owns PRNG progression, temperature scaling and score saturation. The explicit case table has no register or memory latency. Numeric entries are generated by [table generator](../../../tools/llm/generate_tables.py); the source table owns exact values.
