# llm_exp_lut.svh

> **Role:** Combinational U25/F24 samples of exp(-index/16).
> **Scope:** CURRENT. **Category:** GUIDE.
> **Source:** [llm_exp_lut.svh](<../../../Verilog Source code/llm_exp_lut.svh>).

## Important contracts

`llm_exp_sample` takes a 9-bit index. Stored samples cover indices 0…256; default returns zero. Parent softmax owns interpolation and cut-off behavior. The explicit case table has no register or memory latency. Numeric entries are generated by [table generator](../../../tools/llm/generate_tables.py); the source table owns exact values.
